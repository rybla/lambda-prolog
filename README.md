# lambda-prolog

This project is an implementation of λ-prolog higher-order logic programming language in Haskell.
This project is based on and inspired by the book [Programming with Higher-Order Logic](https://sites.google.com/site/proghol/) and related implementations [Teyjus](https://teyjus.cs.umn.edu) and [ELPI](https://github.com/LPCIC/elpi).

## Build

This is a Haskell Stack project. Use the `stack` CLI.

```sh
# build the project
stack build
# run the test suite
stack test
# run the CLI
stack run lambda-prolog
# build the website
stack run build-website
```
